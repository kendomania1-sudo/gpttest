# 기업 3년 분석 앱

회사 이름(또는 티커)을 입력하면 최근 3년간의 **주가 흐름**과 **매출·영업이익·순이익**, **현금흐름(영업/투자/재무/FCF)** 을 보여주는 Streamlit 앱입니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 http://localhost:8501 이 열립니다. 상단 검색창에 회사명을 입력하고 **검색**을 누르세요.
`?q=회사명` 을 주소 뒤에 붙이면 해당 회사로 바로 열립니다 (예: `...streamlit.app/?q=Tesla`).

## 기능
- 회사명 검색: 국내 상장사는 이름 일부만 입력해도 자동완성 목록이 나옵니다 (`kr_listings.py`, `data/kr_listings.csv`가 있으면 전체 상장사 사용). 해외 종목은 영문명/티커 입력 후 Enter
- 주가: 3년 종가 + 20일/120일 이동평균 + 거래량, 3년/1년 수익률 (상장 3년 미만은 상장 이후 수익률). ETF는 주가만 표시
- 손익: 매출·영업이익·순이익 막대그래프, 이익률 추이, 상세 표
- 현금흐름: 영업·투자·재무활동 현금흐름, 잉여현금흐름(FCF)
- 연간 / 분기 전환 (KRW는 조원·억원 단위로 자동 표시)

## 참고
데이터 출처는 Yahoo Finance(yfinance)이며, 연간 재무제표는 보통 최근 4개 회계연도, 분기는 4~5개 분기만 제공됩니다.
